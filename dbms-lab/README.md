# DBMS Lab Programs

This folder contains Database Management System (DBMS) lab programs and exercises.

## Folder Structure

```
dbms-lab/
├── README.md          # This file - Documentation and usage guide
├── sql-queries/       # SQL query files and scripts
├── plsql/            # PL/SQL programs and procedures
├── transactions/     # Transaction management examples
└── assignments/      # Lab assignments and solutions
```

## Usage

### Prerequisites
- MySQL/PostgreSQL/Oracle database installed
- Basic understanding of SQL and database concepts
- Database client tools (MySQL Workbench, pgAdmin, SQL Developer, etc.)

### Running the Programs

1. **SQL Queries**: Execute `.sql` files directly in your database client
2. **PL/SQL Programs**: Run in Oracle SQL Developer or compatible environment
3. **Assignments**: Follow individual assignment instructions in their respective folders

## Topics Covered

- DDL (Data Definition Language) - CREATE, ALTER, DROP
- DML (Data Manipulation Language) - INSERT, UPDATE, DELETE
- DQL (Data Query Language) - SELECT queries
- Joins and Subqueries
- Aggregate Functions and GROUP BY
- Views and Indexes
- Stored Procedures and Functions
- Triggers
- Transaction Management
- Database Design and Normalization
